# Design freeze for v0.3.0

This note freezes the design at tag `v0.3.0`, commit `3430094`. The live
design document and code walkthrough describe this commit. Read them for the
full design. This note records only what changed since the `v0.2.1` freeze
(commit `0e83f78`).

## Delta from the previous freeze

Release 0.3.0 adds three reading features: a text size control, search in more
than one category, and a search drawer. It came in through PR 197 (text size
and multi-category search) and PR 198 (search drawer).

### What landed in the architecture

- **Text size.** The new `src/textZoom.ts` holds `ZOOM_STEPS` (0.8 to 2),
  `nextZoom`, and `readZoom`. `App.tsx` keeps the size in `localStorage` key
  `pfv.textZoom` and sets the root font size to `15 * zoom` px, so every
  `rem` size scales. The header has an **A−**, percent, **A+** group, and
  Command-plus, Command-minus, and Command-0 do the same. The document list
  column is now `16rem` in place of `240px`.
- **Search in more than one category.** The `search` command takes
  `categories: Vec<String>` in place of one `category` string. An empty list
  means all, and the `"all"` value is gone. `Index::search` binds the kinds as
  `,a,b,` and filters with SQL `instr()`. `SearchPanel` replaces the category
  `<select>` with checkboxes and an **All categories** box.
- **Search drawer.** The new `src/SearchDrawer.tsx` holds `SearchPanel` in an
  `aside` that slides out from the right. The **Search** button next to
  **Export**, or Command-F, opens it. The pin is kept in `localStorage` key
  `pfv.searchPinned`. Pinned, it stays open after a result opens and `main`
  gets the `with-drawer` class to make room. A `ResizeObserver` on the header
  sets `--header-h`, so the drawer starts below the header at any text size.
- **Tests.** A Rust test for two categories, two interactive tests (category
  checkboxes, drawer focus, pin, and Escape), `src/textZoom.test.ts`, and new
  e2e checks for the drawer and the text size. The e2e `realKey` now takes an
  AppleScript modifier list, so a check can press Command keys.

### What was removed

The category `<select>` and the `"all"` category value. The search panel no
longer sits in the page flow; it is in the drawer.

### ADRs that shipped

No ADR changed. Two points touch ADRs and are open in the live design
document, section 34:

- ADR-004 says settings live in one file. The text size and the drawer pin
  live in the web view's `localStorage`.
- ADR-003 is unchanged. The category filter is a SQL `WHERE` clause on the same
  FTS5 table, and the index schema is still `"2"`.

### Known gaps carried forward

- FR-006 (previous and next section) and FR-025 (grade findings, REL-002) are
  not built.
- The NFR-009 screen reader checker count is not measured.
- No CI runs the tests.
- New in 0.3.0: the text size, the drawer, and multi-category search have no
  PRD ID, and FR-008 still says "one category or all".
- New in 0.3.0, an assumption not yet checked: the sticky document list keeps
  `top: 64px`, so at a large text size the taller header can cover its top.
