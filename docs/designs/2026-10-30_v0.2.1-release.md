# Design freeze for v0.2.1

This note freezes the design at tag `v0.2.1`, commit `0e83f78`. The live
design document and code walkthrough describe this commit. Read them for the
full design. This note records only what changed since the `v0.2.0` freeze
(commit `d91ffd3`).

## Delta from the previous freeze

Release 0.2.1 is a fix release. It closes three gaps that the 0.2.0 walkthrough
listed, adds one Rust command, and adds a new app icon.

### What landed in the architecture

- **A new command, `export_image`.** `src-tauri/src/prdset/section.rs` reads
  the `.png` next to an `.svg`, as `prd_export.py` embeds, unless the PNG is
  missing or more than 2 s older than the SVG. In that case it reads the SVG.
  Both reads go through `read_asset`, so the path check and the extension
  list still apply. `commands.rs` and `lib.rs` register it. The export path in
  `App.tsx` now calls `export_image`. The viewer still calls `read_asset`.
- **Two body cleaners in place of one.** `src/bodyClean.ts` replaces
  `cleanBody` with `cleanForExport(md, hasDrawing)` and `cleanForView(md)`.
  The export drops a wireframe sketch only when it has the drawing. The viewer
  renders the sketch in a hidden `div[data-sketch]`, and `SectionPage` shows it
  when the drawing fails to load.
- **Images before the Markdown.** `themedExport` in `src/exportRun.ts` loads the
  images from the raw bodies first, then calls `buildExport` with
  `hasDrawing` set from the image map. `loadImages` passes each path as written
  and no longer rewrites `.svg` to `.png`.
- **SVG in Word.** `src/exportDocx.ts` embeds a `data:image/svg+xml` value as an
  SVG, sized by the new `svgSize`, with a 1 by 1 blank PNG fallback for a Word
  older than 2016.
- **Zoom clamp.** `fitView` in `src/zoom.ts` clamps to `MIN_SCALE`, so a very
  large diagram opens at 25%.
- **Tests.** The new `src/interactive.test.tsx` renders React into a JSDOM
  document and drives the diagram window and the hidden sketch with real DOM
  events. The e2e `waitText` helper polls in short scripts. A Rust test pins
  the PNG or SVG choice.
- **Tooling and assets.** `bin/doc_verify.py` now checks citations under
  `src/`, `src-tauri/`, `e2e/`, `scripts/`, and `projects/`. The app icon is
  new, made from `src-tauri/icons/source/icon.svg`.

### What was removed

The two functions above replace `cleanBody`. The release removes nothing that
the author sees.

### ADRs that shipped

No ADR changed. The release stays inside ADR-002: exports still come from
themed HTML and the Motion Word writer. An SVG in a Word file is new, and
ADR-002 does not mention it. The live walkthrough lists this in section 6.2.

### Gaps closed in 0.2.1

- A sketch followed by a link to a missing drawing was hidden. It now stays in
  the export and shows in the viewer, as `prd_export.py` keeps it.
- An export embedded a PNG older than its SVG. It now embeds the SVG.
- `fitView` did not clamp to the 0.25 minimum scale. It now does.

### Known gaps carried forward

- FR-006 (previous and next section) and FR-025 (grade findings, REL-002) are
  not built.
- The NFR-009 screen reader checker count is not measured.
- No CI runs the tests.
- New in 0.2.1: an export can now differ from the `prd_export.py` export when a
  PNG is stale, because the viewer embeds the SVG. A Word older than 2016 shows
  a blank image for that SVG.
