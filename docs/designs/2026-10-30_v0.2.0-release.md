# Design freeze for v0.2.0

This note freezes the design at tag `v0.2.0`, commit `d91ffd3`. The live
design document and code walkthrough describe this commit. Read them for the
full design. This note records only what changed since the `v0.1.0` freeze
(commit `3c33b80`).

## Delta from the previous freeze

Release 0.2.0 is plan 9: diagrams as images, optional grades, and a new visual
design. The Rust core did not change, apart from the version number. Every
change is in the React UI.

### What landed in the architecture

- **One body cleaner.** `src/bodyClean.ts` removes the PRD Forge details block
  and each wireframe sketch that a drawing follows, by the rules of
  `prd_export.py`. `renderBody` and `buildExport` both call it, so the viewer
  and the exports hide the same parts.
- **Diagrams as images in every export.** `ExportBlock` has a new `image`
  block. `loadImages` in `src/exportRun.ts` reads the `.png` of each linked
  `.svg` through the existing `read_asset` command. `exportHtml.ts` draws a
  `figure` with a caption for PDF and print. `exportDocx.ts` embeds the PNG,
  scaled to fit 6.0 by 8.0 inches. A missing PNG exports as the alt text.
- **Optional grades.** `ExportOptions` in `src/exportModel.ts` carries a
  `grades` flag from the new **Include grades** box in `ExportDialog.tsx`.
  The box is clear by default, so the contents table shows only Section and
  Status. FR-019 in the PRD changed to match.
- **Diagram window.** A local image in a body is now a button.
  `src/DiagramViewer.tsx` shows the diagram in a modal dialog with zoom and
  pan by wheel, pinch, drag, buttons, and keys. The pure math is in
  `src/zoom.ts`, from 0.25x to 8x.
- **New visual design.** `src/styles.css` has color tokens, a dark mode, the
  bundled Source fonts, status colors in the document list, and diagrams at
  most 60% of the window height.

### What was removed

The release removes nothing. The contents table no longer shows grades by default,
which is a behavior change, not a removal.

### ADRs that shipped

No ADR changed. The release works within ADR-002: exports still come from
themed HTML and the Motion Word writer. The images reuse the `read_asset`
command, so the NFR-010 rule that nothing remote loads still holds.

### Known gaps carried forward

- FR-006 (previous and next section) and FR-025 (grade findings, REL-002) are
  not built.
- The NFR-009 screen reader checker count is not measured.
- No CI runs the tests.
- New in 0.2.0: `cleanBody` does not check that the drawing file exists, which
  `prd_export.py` does. `fitView` does not clamp to the 0.25 minimum scale.
  The live walkthrough lists both in section 6.
