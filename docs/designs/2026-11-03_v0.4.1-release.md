# Design freeze for v0.4.1

This note freezes the design at tag `v0.4.1`, commit `fbbc944`. The live
design document and code walkthrough describe this commit. Read them for the
full design. This note records only what changed since the `v0.4.0` freeze
(commit `61a8643`).

## Delta from the previous freeze

Release 0.4.1 is a fix release from the plan 11 work items (#207 to #212)
and the export fix #216. It adds no feature and no
command. It closes two gaps that the 0.4.0 freeze carried forward, fixes line
breaks in the exports, and moves the e2e checks off the screen. PRD 0.7.1
answers Q-002 and grades section 7 again.

### What landed in the architecture

- **Live backlog (FR-028 with FR-009).** `WatchState` now holds
  `Mutex<Vec<SetWatcher>>`. `watch_set` starts one watcher on the set and a
  second on the folder that `backlog_of` finds. Both emit `set-changed` with
  the set folder, and a new `backlog` flag marks an event from the backlog
  watcher. In `App.tsx`, the backlog load moved into `loadBacklog`, which
  takes a `stale` check. A backlog event calls it again, and rereads the open
  page when it is a backlog document that changed. `reloadedPage` in
  `src/live.ts` keeps the `folder` of the page.
- **Text size range.** `set_view` in `settings.rs` keeps a size only in 0.8 to
  2, the range of the UI steps. In 0.4.0 the range was 0.5 to 3.0.
- **Line breaks in exports.** `markdownToBlocks` runs the lexer with
  `breaks: false`, and the new `flowSoftBreaks` turns a soft break into one
  space in every prose run. A hard break stays a `\n` run. A strikethrough
  keeps its words. In `exportDocx.ts`, `runs` splits a run on `\n` and writes
  a `TextRun` with `break: 1` between the parts. PDF, print, and Word share
  the fix.
- **Hidden window and e2e background mode.** The window starts hidden
  (`"visible": false` in `tauri.conf.json`), and `setup` shows it. In the
  `mcp-bridge` build, `PFV_E2E_BACKGROUND` sets the `Prohibited` activation
  policy and leaves the window hidden. A second launch skips `set_focus` when
  the variable exists. The harness sets the variable by default, emulates key
  presses in the page, and fails a run whose window is visible.
  `PFV_E2E_KEYS=real` brings back real System Events keys.
- **Commands.** 22, unchanged.
- **Tests.** 17 new tests in `src/exportBlocks.test.ts`. The settings round
  trip also checks 0.5 and 2.5. New e2e checks cover a backlog save while the
  viewer is open, the document list gap at 200%, and Command-F with no set.
  The print panel check runs only with real keys.

### What was removed

- The 0.5 to 3.0 range in `set_view`.
- The single-watcher `Mutex<Option<SetWatcher>>`.
- Item 5 of the extension roadmap (live backlog), now built.

### ADRs that shipped

No ADR changed. ADR-005 now covers two folders per open set. ADR-003 is
unchanged, and the index schema is still `"2"`.

### Open questions closed

The 0.4.0 question "Watch the backlog folder for changes?" is answered: yes,
through `watch_set`.

### Known gaps carried forward

- FR-006 (previous and next section) is not built.
- The NFR-009 screen reader checker count is not measured.
- No CI runs the tests.
- New in 0.4.1: a default e2e run skips the print panel check.
- New in 0.4.1: no unit test covers the backlog path of the `set-changed`
  listener. Only the e2e checks do.
