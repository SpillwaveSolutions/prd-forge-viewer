# Design freeze for v0.1.0

This note freezes the design at tag `v0.1.0`, commit `3c33b80`. The live
design document and code walkthrough describe this commit. Read
them for the full design. This note records only what changed.

## Delta from the previous freeze

This release is the first. No earlier freeze exists, so the delta is all of
release 1 (REL-001): FR-001 to FR-024 except FR-006, and NFR-001 to NFR-010.

### What landed in the architecture

- A Tauri 2 desktop app for macOS: a Rust core and a React UI. Only `App.tsx`
  calls Tauri, and the window has no file system or network permission.
- Set loading from front matter, with unreadable documents marked and not
  fatal (plan 1).
- Start rules, known locations, the settings file, and the `prdf` launcher
  (plan 2).
- Section pages, item views, ID references, and safe body rendering with
  DOMPurify (plan 3).
- Search with BM25 in a per-set SQLite FTS5 index that rebuilds itself on any
  error (plan 4).
- Live changes from OS file events plus a 1 s poll, with a content-hash filter
  (plan 5).
- Built-in and custom export themes (plan 6).
- PDF export through headless Google Chrome, Word export, and print, all
  refused inside any known set (plan 7).
- Release build, e2e checks for every release 1 criterion, and build status in
  REQ and TRAC (plan 8).

### What was removed

Nothing. This release is the first.

### ADRs that shipped

| ADR | Decision | Note |
|-----|----------|------|
| ADR-001 | Tauri 2 with the Motion stack and plugins | As decided. |
| ADR-002 | Motion themes and Word writer, PDF from themed HTML | The print engine is an installed Google Chrome. Bundling Chromium is still open. |
| ADR-003 | BM25 in local SQLite FTS5, one cache file per set | As decided. |
| ADR-004 | `prdf` launcher, one settings file | As decided. |
| ADR-005 | OS file events with debounce and a polling fallback | The poll runs at all times, not only as a fallback. |

### Known gaps carried forward

- FR-006 (previous and next section) and FR-025 (grade findings, REL-002) are
  not built.
- The NFR-009 screen reader checker count is not measured.
- No CI runs the tests.
