# Design freeze for v0.4.0

This note freezes the design at tag `v0.4.0`, commit `61a8643`. The live
design document and code walkthrough describe this commit. Read them for the
full design. This note records only what changed since the `v0.3.0` freeze
(commit `3430094`).

## Delta from the previous freeze

Release 0.4.0 builds two release 2 features early, grade findings (FR-025) and
backlog links (FR-028). It moves the text size and the drawer pin into the
settings file, and fixes two 0.3.0 gaps. PRD 0.7.0 adds FR-026 (text size),
FR-027 (search drawer), and FR-028 to release 2 (REL-002).

### What landed in the architecture

- **Grade findings (FR-025).** The new `read_grade` function in
  `src-tauri/src/prdset/section.rs` and its command in `commands.rs` return
  the body of `grades/<file>` without its front matter, or `None` when there
  is no note. A name with `/` or without `.md` is refused, and the read goes
  through the `inside` path check. In `src/SectionPage.tsx`, `useFindings`
  adds a **Findings** button after the grade. The note renders through
  `renderBody`, so the NFR-010 sanitizer applies.
- **Backlog links (FR-028).** `listed()` takes `backlog.md` as the root when a
  folder has no `prd.md`, so `read_section` and `item_index` work on a
  backlog unchanged. `backlog_of` finds the sibling folder `<set>-backlog`.
  `story_links` reads each `requirements` field and finds the IDs by hand,
  with no regex crate. Two new commands, `backlog` and `story_links`, expose
  them.
- **Backlog in the UI.** In `App.tsx`, `page.folder` is optional and set only
  for a backlog document. `openDoc` takes the folder, and `openItem` looks in
  the set index, then in the backlog index. A `builtBy` map inverts the story
  links. The overview has a **Backlog** section, and the document list has a
  **Backlog** group. `ItemView` shows a **built by** row.
- **View settings in one file.** `Settings` has `text_zoom` and
  `search_pinned`. The `view_prefs` and `save_view_prefs` commands read and
  save them through the locked atomic `update_settings`. `set_view` keeps a
  size only in 0.5 to 3.0. The UI saves nothing until it has read the stored
  values, through the `prefsRead` ref.
- **Fixes.** `.doc-nav` uses `--header-h` for `top` and `max-height`, so a
  tall header does not cover the document list. Command-F needs an open set,
  through the `hasSet` ref.
- **Commands.** 22, up from 17.
- **Tests.** Five Rust tests for `read_grade`, the backlog, and story links,
  one settings round trip, one interactive test for **Findings**, one static
  test for **built by**, and e2e checks for FR-025, FR-028, the settings file,
  and the document list gap.

### What was removed

`localStorage` is no longer used. The keys `pfv.textZoom` and
`pfv.searchPinned` are gone, and a value stored by 0.3.0 is not migrated.

### ADRs that shipped

No ADR changed. ADR-004 (one settings file) now holds for every setting.
ADR-003 is unchanged, and the index schema is still `"2"`.

### Open questions closed

This release answers four 0.3.0 questions: settings in one file, the
document list top, Command-F with no set, and PRD IDs for the 0.3.0 features.

### Known gaps carried forward

- FR-006 (previous and next section) is not built.
- The NFR-009 screen reader checker count is not measured.
- No CI runs the tests.
- New in 0.4.0: the backlog is read once when the set opens, and the watcher
  does not cover it.
- New in 0.4.0: `set_view` keeps 0.5 to 3.0, and `readZoom` keeps only the
  steps 0.8 to 2.
